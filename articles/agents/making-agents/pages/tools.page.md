# Agent Tools

## Research Agents

Use for reading, searching, understanding:

- `Read`, `Glob`, `Grep`, `Bash`

## Builder Agents

Use for implementing, writing, fixing:

- `Read`, `Write`, `Edit`, `Glob`, `Grep`, `Bash`

## Data Agents

Use for queries and database access:

- `Read`, `Bash`, database tools

## Linting Agents

Use for code quality:

- `Read`, `Write`, `Edit`, `Glob`, `Grep`, `Bash`
