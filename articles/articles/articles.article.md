# Articles

The articles system organizes knowledge into articles, skills, and pages.

## Skills

- **list** — list articles from manifest
- **read** — read a file by path
- **peek** — peek frontmatter only
- **create** — create article, skill, or page
- **update** — update frontmatter or content
- **delete** — delete article, skill, or page
- **regenerate** — regenerate manifest

## Pages

- **overview** — what articles are and the three types
- **anatomy** — file types, frontmatter, naming, reference files
- **usage** — how to work with articles and best practices
- **agents** — stock agents that come with directive
