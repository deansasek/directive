# Tools Setup

## Claude Code

```bash
brew install anthropic/claude-code/claude
claude auth
```

## tmux

```bash
brew install tmux
```

## oh-my-zsh

```bash
sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

## Git

```bash
xcode-select --install
```
