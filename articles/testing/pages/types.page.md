# Test Types

## Unit

Test a single function or class in isolation. Fast, deterministic.

## Integration

Test how components work together. Slower, may need a database or server.

## End-to-End

Test the full user flow through the application. Slowest, most expensive.

## When to Use

| Type | Use when |
|------|---------|
| Unit | Logic, algorithms, utility functions |
| Integration | API endpoints, database queries |
| E2E | Critical user journeys |
