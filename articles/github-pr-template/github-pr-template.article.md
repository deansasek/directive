# GitHub PR Template

Standardized PR body for human-readable code review.

## Template

```markdown
## Description
<!-- what changed and why -->

## Related Issues
<!-- Fixes PROJ-1234 -->

## Type of Change
- [ ] Bug fix
- [ ] New feature
- [ ] Breaking change
- [ ] Refactor / Performance / Tech Debt

## How Has This Been Tested?
- [ ] Unit tests
- [ ] Integration tests
- [ ] Manual smoke test

## Checklist
- [ ] Style guidelines
- [ ] Self-review
- [ ] Documentation
- [ ] Security implications
```
