# GitHub PR Commits

Conventional commits: machine-readable git history for automated changelogs.

## Format

```
<type>(<scope>): <imperative summary>
```

Examples:
- `fix(auth): prevent session drop on 503`
- `feat(billing): add Stripe webhook`

## Skills

- **validate** — check a commit against the standard
- **suggest** — generate a commit from a description

## Pages

- **types** — when to use each type
- **format** — header, body, footer structure
- **examples** — valid and invalid commits
