# Format

## Header (required)

```
<type>(<scope>): <summary>
```

- Imperative, lowercase, under 72 chars
- No period at end

## Body (optional)

Explain what and why — not how.

## Footer (optional)

```
Closes PROJ-1234
BREAKING CHANGE: <description>
```
