# SOLID

## SRP — Single Responsibility

A class or module should have one clear reason to change.

## OCP — Open/Closed

Open for extension, closed for modification. Add behavior by adding code, not by changing existing code.

## LSP — Liskov Substitution

Objects should be replaceable with subtypes without breaking the application.

## ISP — Interface Segregation

Many specific interfaces are better than one broad interface.

## DIP — Dependency Inversion

Depend on abstractions, not on concrete implementations.
