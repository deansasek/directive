# Foundations

## DRY — Don't Repeat Yourself

Every piece of knowledge should have a single, authoritative representation. Duplication causes bugs when updates are missed.

## KISS — Keep It Simple, Stupid

Write straightforward code. Avoid unnecessary complexity.

## YAGNI — You Aren't Gonna Need It

Don't build features until they are actually required.

## Separation of Concerns

Divide code into distinct sections, each addressing a separate concern.
