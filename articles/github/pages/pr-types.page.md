# PR Types

| Type | Use for |
|------|---------|
| `feat` | New feature |
| `fix` | Bug fix |
| `refactor` | Code restructure |
| `perf` | Performance |
| `test` | Tests |
| `chore` | Dependencies, tooling |
| `ci` | CI/CD |
| `infra` | Infrastructure |
| `docs` | Documentation |
| `style` | Formatting |

Breaking changes: append `!` → `feat(api)!:`
