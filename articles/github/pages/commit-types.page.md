# Types

| Type | Use when |
|------|---------|
| `feat` | New behavior |
| `fix` | Bug fix |
| `refactor` | Code restructure |
| `perf` | Performance |
| `test` | Tests |
| `chore` | Dependencies, tooling |
| `ci` | CI/CD |
| `infra` | Infrastructure |
| `docs` | Documentation |
| `style` | Formatting |

Breaking: `feat(api)!:` or `BREAKING CHANGE:` footer.
