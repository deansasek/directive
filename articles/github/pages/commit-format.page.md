# Format

## Header (required)

```
<type>(<scope>): <summary>
```

Imperative, lowercase, under 72 chars, no period.

## Body (optional)

Explain what and why — not how.

## Footer (optional)

```
Closes PROJ-1234
BREAKING CHANGE: <description>
```
